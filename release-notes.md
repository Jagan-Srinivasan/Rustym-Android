# Rustym v1.0.7 🎵

**True crossfade is here.** Songs now melt into each other instead of hard-cutting — plus one cleanup in the auto-updater.

---

## ✨ What's new

### 🎚️ Premium crossfade between songs
- Turn on **Settings → Playback → Skip fade** (now a real crossfade, up to 8 seconds) and songs **overlap**: the outgoing track keeps playing while the next one fades in underneath
- Works on **both paths** — natural end-of-track *and* tapping next / swiping the card
- The fade is sample-accurate handover: the new song starts exactly where the fade began, no jump, no restart, no double-play
- If you seek, skip or pause mid-fade, playback hands back to the main player instantly
- Set it to 0s for hard cuts if you prefer

### 🧹 Auto-update cleanup
- The downloaded update APK is now **deleted right after the install is staged** (and on any failure), so no update files linger in storage — bytes move straight into the install session, then the temp copy is gone

---

## ✨ Still new in 1.0.x (if you're jumping several versions)
- 👆 **Swipe the Now Playing card left / right** to change songs
- 🎚️ **Swipe up / down on the album art** for volume — blinks when it hits 0 until you raise it
- 🤖 **Auto-update & install** in the background (Settings → Updates)
- 🎓 **One-time gesture tutorial** · 📝 **lyrics switch** · 🧹 **cleaner Settings** · 🔄 **startup update check**
