# Rustym v1.0.5 🎵

**Updates now install themselves.** Flip one switch and Rustym keeps itself current in the background — plus a clearer volume gesture. All the earlier features (Now Playing gestures, one-time tutorial, lyrics switch, cleaner Settings) are included.

---

## ✨ What's new

### 🤖 Auto-update & install
- New **Settings → Updates → "Auto-update & install"** switch
- When it's on, Rustym **checks GitHub, downloads the new APK and stages the install in the background** — you only get Android's one-tap "Update" confirmation (a requirement of Android for sideloaded apps, nothing we can skip)
- Turned on once, it keeps working: **every future app start quietly fetches and stages the newest version** while you listen
- Live progress ("Downloading… 43%") right in the Updates card
- Rustym now declares the "install packages" permission so it can stage its own updates

### 🔊 Volume gesture, clearer at zero
- Swipe the album art **all the way down to 0** and a **"Volume is 0 · swipe up to increase"** pill stays on screen until you actually raise the volume — no more silent confusion
- Normal volume pill still fades out a moment after any other level

---

## ✨ Still new in 1.0.x (if you're jumping several versions)
- 👆 **Swipe the Now Playing card left / right** to change songs
- 🎚️ **Swipe up / down on the album art** to change the volume
- 🎓 **One-time gesture tutorial** right after updating — never shown again afterwards
- 📝 **Settings → Lyrics** switch to turn lyrics on or off
- 🧹 **Cleaner Settings page** with consistent switch rows
- 🔄 **Automatic update check** at startup with a formatted "What's new" dialog

---

## 📲 Install
1. Download **Rustym.apk** below and install it (allow "Install unknown apps" for the source once)
2. Open Settings → Updates and switch on **Auto-update & install**
3. That's it — future updates arrive themselves; you just tap "Install" when Android asks
