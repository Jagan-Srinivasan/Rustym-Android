# Rustym v1.0.3 🎵

**Hotfix on top of v1.0.2.** All the v1.0.2 features are here — Now Playing gestures, the one-time tutorial, the lyrics switch, the cleaner Settings page and the built-in update check — plus one reliability fix:

---

## 🔧 Fixed
- **"What's new" now shows reliably after every update.** On some upgrades from v1.0.1 the dialog was skipped on the first launch. Upgrading devices are now detected properly, and the release notes greet you exactly once.

---

## ✨ Still new in 1.0.x (if you're jumping several versions)
- 👆 **Swipe the Now Playing card left / right** to change songs
- 🎚️ **Swipe up / down on the album art** to change the volume, with a live volume pill
- 🎓 **One-time gesture tutorial** right after updating — never shown again afterwards
- 📝 **Settings → Lyrics** switch to turn lyrics on or off
- 🧹 **Cleaner Settings page** with consistent switch rows
- 🔄 **Automatic update check** at startup, plus a "What's new" dialog after every update

---

## 📲 Install
1. Download **Rustym.apk** below
2. Open the file and install it (allow "Install unknown apps" if Android asks)
3. Updating keeps your favourites, history, settings and offline cache — nothing is lost
